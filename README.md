# 划词翻译

一个运行在 Tampermonkey / Violentmonkey 上的全网划词翻译脚本。选中网页文字即弹翻译气泡，按 `Alt+Q` 框选图片/表格/图表可 OCR 翻译，按 `Alt+A` 打开常驻翻译面板。界面语言跟随你选择的目标语言。

## 功能

- **划词翻译**：选中 2–2000 字符，旁边自动弹出翻译气泡
- **框选翻译（OCR）**：按 `Alt+Q`，拖拽选中任意网页区域，图片、Canvas、图表自动识别文字并翻译
- **常驻翻译框**：按 `Alt+A` 开关，可输入/粘贴文字，拖动调整位置和大小
- **单词词典模式**：选中英文单词自动查词典，显示音标、词性、释义、例句
- **流式输出**：GLM 引擎逐字输出翻译结果
- **多引擎自动降级**：一个引擎失败自动切下一个，几乎总有结果
- **自动跳过代码**：`pre`、`code`、`.blob-code`、diff 表格等代码区域不翻译
- **同语检测**：源语言和目标语言相同时不调用接口
- **按站开关**：每个网站可独立启用/禁用
- **敏感页保护**：银行、支付、邮箱等页面自动禁用
- **历史与缓存**：保留最近 50 条翻译，重复内容走本地缓存

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)
2. 打开 [GitHub中文翻译.user.js](./GitHub中文翻译.user.js)，点 **Raw** 视图，Tampermonkey 会弹出安装页，点 **安装**
3. 打开任意网页划词即可使用

## 使用步骤

下面有 **简易版** 和 **详细版** 两种说明，新手看简易版够用，想了解全部功能看详细版。

### 简易版（30 秒上手）

1. 选中网页上任意文字，旁边会弹出翻译气泡
2. 想翻译图片/截图区域：按 `Alt+Q`，拖拽框选，松手自动翻译；按 `Esc` 取消
3. 想固定一个翻译窗口：按 `Alt+A` 开关常驻翻译框
4. 点右下角悬浮球可以切换目标语言（简中/繁中/英/日/韩）和翻译引擎

就这四件事，够用了。

### 详细版（全部功能）

**基础划词**

- 选中任意网页文字，气泡自动出现，显示翻译结果
- 点气泡右上角复制按钮可复制译文
- 按 `Esc` 或点 × 关闭气泡

**框选翻译（OCR）**

- 按 `Alt+Q` 进入框选模式，鼠标变成十字
- 拖拽选中网页任意矩形区域，松手后自动截图、OCR、翻译
- 适合：图片里的文字、Canvas 图表、截图、代码截图
- 按 `Esc` 取消框选回到翻译框
- 首次使用会加载截图库，稍慢；之后从浏览器缓存读，很快

**常驻翻译框**

- 按 `Alt+A` 打开/关闭常驻翻译框
- 框内可直接输入或粘贴文字，实时翻译
- 拖动标题栏移动位置，拖右下角调整大小
- 位置和大小按网站记住，下次打开还是原来那样

**悬浮球与设置**

- 右下角有个 ⚡/🧠 小球，点击打开设置面板
- 设置面板里可以：
  - 切换目标语言（简中/繁中/英/日/韩）
  - 切换翻译引擎：⚡ 快速（Edge + MyMemory 兜底）/ 🧠 精准（GLM 流式）
  - 在当前网站启用/禁用翻译
  - 查看最近 50 条翻译历史，点击填入常驻框
  - 清空历史、清理缓存
- 悬浮球本身可以拖动，位置记住

**单词词典**

- 选中一个英文单词，自动进入词典模式
- 显示音标、词性、释义、例句
- 比纯翻译更详细，适合查单词

**快捷键汇总**

| 操作 | 快捷键 |
| --- | --- |
| 划词翻译 | 鼠标选中文字 |
| 框选/OCR 模式 | `Alt+Q`（拖拽；`Esc` 取消） |
| 开关常驻翻译框 | `Alt+A` |
| 关闭气泡 | `Esc` 或点 × |

## 目标语言

简体中文 · 繁體中文 · English · 日本語 · 한국어

## 引擎

| 模式 | 降级链 |
| --- | --- |
| ⚡ 快速 | Edge 免费翻译 → MyMemory → GLM |
| 🧠 精准 | GLM 流式 → Edge → MyMemory |

## 注意事项

- 脚本全局匹配 `*://*/*`，但在敏感页面和你手动禁用的网站上不显示任何界面
- 大图片 OCR 首次较慢，之后走缓存
- 翻译结果仅供参考，专业术语和长句请对照原文
